# Shared-skeleton Boolean configuration lifting

Each fact vector contains one bit per static plan. Optional clears AND with the valuations disabling the atom; joins and commit OR. A use observes taint after selected pre-edge clears and before action update. Bad vectors are indexed by exact event/delivery/peak-depth triples. Plan projection commutes with these operations, and topological induction gives the same existential fact interpretation as concrete execution. Filtering by a smaller cap preserves exact bad-prefix queries by resource monotonicity.

The separately coded module imports no frontier-mask or direct-fact operations. It shares the model successor relation, so evidence concerns symbolic transfer and query representation rather than an independently specified time quotient. The strict-DBM oracle supplies a different timing representation. The local program instantiates the configuration-lifting idea cited to SPLlift; SPLlift itself was not executed and no BDD comparison is claimed.

Run `python3 compare_lifting.py --output results/lift-local --compare results/lifting/reference.json`. Full actual models, query bit vectors, optimum sets and operation categories are retained. Dense logical bit counts, mask-entry counts and timing have different units; no physical memory ratio or speed superiority is inferred.
